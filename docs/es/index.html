EnderElevator

Viaje vertical con magia ender.

Salta para subir, agachate para bajar. EnderElevator agrega transporte vertical simple, seguro y configurable para servidores y mundos de Hytale.

Como funciona

Parate sobre el bloque. El movimiento hace el resto.

01

Salta para subir

El sistema busca hacia arriba el siguiente elevador equivalente en la misma columna X/Z.

02

Agachate para bajar

Mantener agacharse busca hacia abajo el siguiente elevador equivalente.

03

Teletransporte seguro

El destino debe tener dos bloques vacios encima para que el jugador no llegue dentro de un techo.

Instala en 3 pasos

Descarga, coloca, habilita.

  1. CurseForge

    Instala con la app de CurseForge o descarga el jar mas reciente.

  2. Mods folder

    Coloca el mod en la carpeta de mods del servidor o cliente Hytale de tu setup.

  3. World settings

    Activa el mod en el mundo o servidor y manten las versiones alineadas.
