Historial de versiones

Historial de versiones reflejado desde CHANGELOG.md.

Actualizado 2026-06-04EnderElevator 1.1.4
Historial localizado

Esta pagina traduce el historial publico de releases; los identificadores de version y nombres de items permanecen como en el proyecto.

[1.1.4] - 2026-06-04

Probado en HytaleServer v2026.04.30-b4f6a911e (pre-release, release)

Actualizacion de compatibilidad

  • Compatibilidad con Hytale: EnderElevator fue actualizado para soportar versiones mas nuevas de Hytale 0.5+.
  • Sistema de teletransporte: se ajusto el comportamiento de teletransporte del elevador para el engine/runtime mas nuevo, corrigiendo casos donde podia fallar, comportarse de forma inesperada o cerrar el juego.
  • Assets de item: los IDs de los items del elevador fueron actualizados para coincidir con los nombres esperados por versiones mas nuevas de Hytale.

[1.1.3] - 2026-01-19

Cambios

Las recetas de las variaciones del elevador cambiaron de flores a petalos.

Nuevas recetas:

Yellow: Ender Elevator + Petals Yellow
Purple: Ender Elevator + Petals Purple
Red: Ender Elevator + Petals Red
Orange: Ender Elevator + Petals Yellow + Petals Red
Cyan: Ender Elevator + Petals Cyan
Violet: Ender Elevator + Petals Purple + Petals Blue
Brown: Ender Elevator + Petals Red + Petals Green
Pink: Ender Elevator + Petals Pink
Green: Ender Elevator + Petals Green
Black: Ender Elevator + Petals Red + Petals Blue + Petals Yellow
Blue: Ender Elevator + Petals Blue

[1.1.2] - 2026-01-18

Correcciones

Logica de teletransporte: corregido un problema donde el teletransporte del elevador podia comportarse de forma inesperada o fallar.

Estabilidad del sistema: resueltos errores internos ligados al manejo de Teleport.create para asegurar un viaje vertical mas suave.

[1.1.1] - 2026-01-16

Hotfixes

Drop de bloques: corregido un problema donde romper cualquier bloque Ender Elevator no soltaba el item del elevador.

Ahora se suelta el item correcto al romper el bloque, incluidas todas las variaciones de color.

[1.1] - 2026-01-15

Nuevas funciones

Variaciones de color: agregadas 11 nuevas versiones de color del Ender Elevator para combinar con distintos estilos de construccion.

Colores incluidos: Yellow, Purple, Red, Orange, Cyan, Violet, Brown, Pink, Green, Black y Blue.

Crafting

Implementadas recetas para todas las variaciones de color del elevador. Se fabrican en Furniture Bench combinando un Ender Elevator base con flores o items especificos.
