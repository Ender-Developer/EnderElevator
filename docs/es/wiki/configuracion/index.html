Configuracion

Documenta cada clave: distancia de busqueda, CooldownMs, sonido de teletransporte, movimiento suave y SmoothingDurationMs.

Actualizado 2026-06-04EnderElevator 1.1.4
Claves de config

config.json es gestionado por el sistema de config de Hytale. Estas claves son exactas y distinguen mayusculas.

Config predeterminada

json
{
  "MaxSearchDistance": 320,
  "CooldownMs": 500,
  "EnableSound": false,
  "EnableSmoothMovement": false,
  "SmoothingDurationMs": 320
}

Referencia de config

ClaveTipoPredeterminadoDescripcionEfecto en juegoRecomendado
MaxSearchDistanceinteger320Rango maximo de busqueda vertical, en bloques.Valores mayores permiten pozos mas altos, pero cuestan mas busqueda si no hay destino.160-320
CooldownMslong500Pausa entre usos exitosos del elevador.Evita reusos accidentales mientras se mantiene salto o agacharse.400-700
EnableSoundbooleanfalseActiva el sonido de teletransporte.Reproduce SFX_Portal_Neutral_Teleport_Local despues de un teletransporte exitoso.false for quiet servers
EnableSmoothMovementbooleanfalseUsa movimiento suave corto en lugar de teletransporte instantaneo.Mueve por el hueco con interpolacion y aplica un teletransporte final de correccion.true for visual polish
SmoothingDurationMsinteger320Duracion del movimiento suave en milisegundos.Limitado entre 180 y 650 ms para que el movimiento suave siga respondiendo.260-380

Ejemplo de movimiento suave

json
{
  "MaxSearchDistance": 240,
  "CooldownMs": 550,
  "EnableSound": true,
  "EnableSmoothMovement": true,
  "SmoothingDurationMs": 320
}
