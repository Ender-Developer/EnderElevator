EnderElevator

Vertical travel, powered by ender magic.

Jump to go up, crouch to go down. EnderElevator adds simple, safe, configurable vertical transport to Hytale servers and worlds.

Download Open Wiki GitHub
11 color variations
How it works

Stand on the block. Let movement do the rest.

01

Jump to go up

The system searches upward for the next matching elevator block in the same X/Z column.

02

Crouch to go down

Hold crouch to search downward for the next matching elevator below your feet.

03

Teleport safely

The destination must have two empty blocks above it, so players do not arrive inside a ceiling.

Built for players and server owners

Practical transport without command spam.

11 color variations

Build elevators that match stone halls, gardens, libraries, and arcane rooms.

Configurable search distance

Tune MaxSearchDistance for compact builds or very tall shafts.

Cooldown configuration

Use CooldownMs to keep repeated travel deliberate.

Optional sound

Enable teleport sound only when the server wants audible feedback.

Optional smooth movement

Enable smooth movement for a short interpolated travel effect.

Block sprites

Install in 3 steps

Download, place, enable.

  1. CurseForge

    Install through the CurseForge app or download the latest jar.

  2. Mods folder

    Place the mod in the Hytale server or client mods folder used by your setup.

  3. World settings

    Enable the mod for the world or server and keep versions aligned.
