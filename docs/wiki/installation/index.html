Getting Started

Installation

Download EnderElevator, install it in Hytale, and keep worlds or servers on the supported build.

Updated 2026-06-04EnderElevator 1.1.4
Compatibility

Use the supported Hytale build listed on the Compatibility page. Do not assume unsupported builds are safe.

Where to download

Download the current release from CurseForge first. GitHub releases and source are useful for contributors, but CurseForge is the public distribution page.

CurseForgeGitHub releases

Install steps

  1. Download the mod

    Use EnderElevator-1.1.4.jar or the latest CurseForge file.

  2. Place it in the mods folder

    Install through CurseForge or place the mod files into the Hytale server/client mods folder used by your setup.

  3. Enable it for the world

    Start Hytale, enable the mod where required, and confirm the asset pack loads with the mod.

Server and modpack note

For servers and modpacks, keep all players on the same mod jar and Hytale build.
