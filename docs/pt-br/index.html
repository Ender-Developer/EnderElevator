EnderElevator

Viagem vertical com magia ender.

Pule para subir, agache para descer. EnderElevator adiciona transporte vertical simples, seguro e configuravel para servidores e mundos de Hytale.

Download Abrir wiki GitHub
11 variacoes coloridas
Como funciona

Fique sobre o bloco. O movimento faz o resto.

01

Pule para subir

O sistema busca para cima o proximo elevador equivalente na mesma coluna X/Z.

02

Agache para descer

Segure agachar para buscar abaixo dos seus pes o proximo elevador equivalente.

03

Teleporte seguro

O destino precisa ter dois blocos vazios acima para o jogador nao chegar dentro do teto.

Feito para jogadores e servidores

Transporte pratico sem comandos.

11 color variations

Build elevators that match stone halls, gardens, libraries, and arcane rooms.

Configurable search distance

Tune MaxSearchDistance for compact builds or very tall shafts.

Cooldown configuration

Use CooldownMs to keep repeated travel deliberate.

Optional sound

Enable teleport sound only when the server wants audible feedback.

Optional smooth movement

Enable smooth movement for a short interpolated travel effect.

Instale em 3 passos

Baixe, coloque, habilite.

  1. CurseForge

    Instale pelo app CurseForge ou baixe o jar mais recente.

  2. Mods folder

    Coloque o mod na pasta de mods do servidor ou cliente Hytale do seu setup.

  3. World settings

    Habilite o mod no mundo ou servidor e mantenha as versoes alinhadas.
