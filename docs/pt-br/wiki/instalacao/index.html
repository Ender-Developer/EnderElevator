Comece aqui

Instalacao

Baixe EnderElevator, instale no Hytale e mantenha mundos ou servidores na versao suportada.

Atualizado 2026-06-04EnderElevator 1.1.4
Compatibilidade

Use a build de Hytale listada em Compatibilidade. Nao assuma que builds nao suportadas sao seguras.

Onde baixar

Baixe a versao atual pelo CurseForge primeiro. Releases do GitHub e codigo ajudam contribuidores, mas CurseForge e a pagina publica de distribuicao.

CurseForgeReleases do GitHub

Passos de instalacao

  1. Baixe o mod

    Use o arquivo EnderElevator-1.1.4.jar ou o arquivo mais recente do CurseForge.

  2. Coloque na pasta de mods

    Instale pelo CurseForge ou coloque os arquivos do mod na pasta de mods do servidor/cliente Hytale usada pelo seu ambiente.

  3. Habilite no mundo

    Inicie o Hytale, habilite o mod onde necessario e confirme que o asset pack carrega com o mod.

Nota para servidores e modpacks

Para servidores e modpacks, mantenha todos os jogadores no mesmo jar e build do Hytale.
