Docs de servidor

Configuracao

Documenta cada chave: distancia de busca, CooldownMs, som de teleporte, movimento suave e SmoothingDurationMs.

Atualizado 2026-06-04EnderElevator 1.1.4
Chaves de config

config.json e gerenciado pelo sistema de config do Hytale. Estas chaves sao exatas e diferenciam maiusculas.

Config padrao

json
{
  "MaxSearchDistance": 320,
  "CooldownMs": 500,
  "EnableSound": false,
  "EnableSmoothMovement": false,
  "SmoothingDurationMs": 320
}

Referencia de config

ChaveTipoPadraoDescricaoEfeito no jogoRecomendado
MaxSearchDistanceinteger320Alcance maximo de busca vertical, em blocos.Valores maiores permitem elevadores mais altos, mas custam mais busca quando nao ha destino.160-320
CooldownMslong500Intervalo entre usos bem-sucedidos do elevador.Evita reuso acidental enquanto pulo ou agachar fica pressionado.400-700
EnableSoundbooleanfalseAtiva o som de teleporte.Toca SFX_Portal_Neutral_Teleport_Local apos um teleporte bem-sucedido.false for quiet servers
EnableSmoothMovementbooleanfalseUsa movimento suave curto em vez de teleporte instantaneo.Move pelo vao com interpolacao e aplica um teleporte final de correcao.true for visual polish
SmoothingDurationMsinteger320Duracao do movimento suave em milissegundos.Limitado entre 180 e 650 ms para manter o movimento suave responsivo.260-380

json
{
  "MaxSearchDistance": 240,

  "SmoothingDurationMs": 320
}
